# Progra-3
Este proyecto es un sistema de estacionamiento. En cual permite registrar la entrada y salida de vehículos (autos, motos y camionetas), asignarles un cajón disponible, generar un boleto con la hora de entrada y calcular el monto a pagar según el tiempo pasado y el tipo de vehículo.


Funcionalidad
El programa permite:

Registrar la entrada de un vehículo y asignarle un cajón libre
Consultar cuántos cajones están disponibles en tiempo reel
Generar un boleto con el ID del vehículo y la hora de entrada
Calcular el costo según la tarifa por tipo de vehículo
Procesar el cobro y generar un recibo de salida
Mostrar el estado general del estacionamiento en el panel de control

El sistema maneja tres tipos de vehículos:

Auto — tarifa estándar
Moto — tarifa reducida
Camioneta — tarifa alta por ocupar más espacio
